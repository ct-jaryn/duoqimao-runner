## 🎮 游戏简介

夺旗猫街区挑战赛开跑了！你的猫猫会自动向右奔跑，速度随距离不断加快。沿途有断裂的地面、高耸的管道、来回巡逻的怪物和 1000 米后出现的飞鸟。踩到怪物头顶可以反弹得分，撞到它们则会掉血；每吃满 10 枚金币回复 1 点生命。坚持冲刺 3000 米抵达终点旗帜，即可完成挑战。

## ✨ 功能特性

- **双角色可选**：开局前在「小黑」（3 滴血 · 跳得高）和「大壮」（4 滴血 · 跳得低）之间切换，属性差异真实生效
- **二段跳机制**：空中可再跳一次，踩怪反弹后还会补充跳跃次数
- **金币回血**：每枚金币 +10 分，集满 10 枚自动回复 1 点生命（满血时提示"生命已满"）
- **踩怪得分**：从上方踩中怪物 +30 分并反弹，侧面碰撞则掉血并获得 1 秒无敌时间
- **渐进难度**：奔跑速度持续提升，地形缺口、敌人密度随距离增加，1000 米后开始出现正弦轨迹的飞鸟
- **程序化生成关卡**：随机生成地面板块、悬空平台、管道障碍与三种高度/弧线的金币组
- **像素帧动画**：角色跑动/跳跃使用逐帧 WebP 精灵序列，金币为 8 方向旋转切片动画，并带粒子爆裂特效
- **Web Audio 音效与 BGM**：振荡器合成的跳跃、吃币、踩怪、受伤、胜利等音效及循环背景音乐，可一键开关
- **完整游戏状态**：开始选角 → 进行 → 暂停（P 键）→ 胜利/失败结算 → 再来一局

## 🕹️ 操作说明

| 操作 | 键盘 | 触屏/鼠标 |
| --- | --- | --- |
| 跳跃 / 二段跳 | `空格` 或 `↑` | 点击画面或「跳跃 / 二段跳」按钮 |
| 暂停 / 继续 | `P` | 点击暂停弹层中的「继续」按钮 |
| 开始 / 再来一局 | `Enter`（非进行中） | 点击「开始奔跑」/「再来一局」 |
| 选择角色 | — | 点击开始界面的角色卡片 |
| 音效开关 | — | 点击右上角「音效：开/关」按钮 |

## 🛠️ 技术栈

- **HTML5 Canvas 2D**：960×540 画布渲染整个游戏世界（基于 `requestAnimationFrame` 的主循环）
- **原生 JavaScript（ES6+）**：无任何框架与第三方依赖，单文件游戏逻辑
- **CSS3**：界面布局、HUD、弹层与响应式样式
- **Web Audio API**：振荡器实时合成音效与 8-bit 风格背景音乐
- **资源**：WebP 逐帧精灵图 + GIF 备用素材，纯静态加载

## 🚀 快速开始

本项目为**纯静态站点**，没有 `package.json`，无需安装依赖、无需构建打包。

### 方式一：本地静态服务器（推荐）

在项目根目录任选其一：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# 或
npx http-server -p 8000
```

然后浏览器访问 <http://localhost:8000>。

### 方式二：直接打开

直接双击 `index.html` 用浏览器打开即可游玩（所有资源均为相对路径的 `<img>` 加载）。

### 部署

将整个目录原样上传到任意静态托管（GitHub Pages、Netlify、Vercel、Nginx 等）即可，无构建步骤。
