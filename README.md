# 夺旗猫跑酷（Duoqimao Runner）

> 纯前端像素风横版跑酷闯关游戏：三只技能各异的猫咪、6 个主题关卡、连击与道具系统、终点夺旗演出，以及第 6 关的机械犬 BOSS 战。无需构建、无需依赖，打开即玩。

## 🎮 游戏简介

夺旗猫街区挑战赛开跑了。猫猫自动向右冲刺，你要在断裂的地面、管道、尖刺、巡逻怪和飞鸟之间一路冲到终点，拔下旗帜。每个关卡都有不同的地形权重、敌人工种、天气氛围与背景音乐；进度、星级和最高分会保存在本地，逐关解锁更强的挑战。第 6 关的旗塔前，夺旗大盗的机械犬正在等你。

## ✨ 功能特性

### 关卡与进程
- **6 个主题关卡**：晨光街区 → 喷泉公园 → 霓虹后巷 → 塔吊工地 → 月光屋顶 → 夺旗决战，每关独立配色、视差装饰（树/喷泉/霓虹牌/塔吊/屋顶/旗塔）、氛围粒子与 BGM
- **差异化关卡生成器**：每关配置自己的缺口宽度、地块长度、敌人密度、飞鸟频率、悬浮/移动平台概率、尖刺概率与宝石密度，难度随距离推进
- **解锁链与星级评价**：通关解锁下一关；按分数门槛结算 1–3 星，累计 5 星解锁第三名角色
- **本地存档**：关卡星级、每关最高分、最高连击、累计金币、出场角色与音效设置全部写入 `localStorage`
- **终点夺旗演出**：抵达目标距离后自动生成平坦冲刺段与终点旗，抓旗后彩带爆裂 + 结算面板

### 玩法系统
- **BOSS 战（第 6 关）**：机械犬会冲锋、投弹并显示落点警告圈，跳踩头部三次击毁，世界会在战斗期间定格成竞技场
- **三段位角色**：小黑（3 血 / 3 段跳 / 疾影冲撞）、大壮（5 血 / 震地猛击）、雪球（4 血 / 时缓步伐，需解锁）
- **连击倍率**：连续拾取与踩怪累积最高 x8 倍率，HUD 内置衰减条，受伤清零
- **5 种道具**：金币磁铁、护盾、无敌之星（分数翻倍）、回血心、火箭冲刺，带拾取提示与画布光环特效
- **金币回血 + 宝石**：每 12 枚金币回 1 血，宝石 +120 分并计入结算奖励
- **敌人生态**：grunt / 冲刺者 / 盾卫可踩杀，紫色尖刺怪与地面尖刺只能跳过；飞鸟只在空中构成威胁
- **手感优化**：跳跃缓冲、土狼时间、掉落救援弹台（不再在坑里反复掉血）、踩怪反弹补跳、屏幕震动与受击闪红

### 界面与交互
- **画布内 HUD**：生命心形、增益标签、关卡进度条（含终点旗标）、分数、连击倍率、金币/宝石计数、技能冷却按钮
- **完整屏流程**：主菜单 → 选关（锁定态 / 星级 / 最高分）→ 倒计时 → 游戏 → 暂停 → 结算（星级动画 + 得分明细 + 下一关）
- **菜单背景实时演示**：主界面下由同一套模拟器自动跑图，无需额外代码路径
- **多端输入**：键盘（空格/↑/W、Shift/X、P、R、M、N、Esc、Enter）、鼠标点击画布、移动端跳跃与技能大按钮
- **失焦自动暂停**、BGM 与音效独立开关、`prefers-reduced-motion` 适配、无高亮闪烁的焦点环

## 🚀 快速开始

纯静态站点，没有 `package.json`，无需安装依赖或构建。

```bash
# 任选其一，然后访问 http://localhost:8000
python -m http.server 8000
npx serve .
npx http-server -p 8000
```

也可以直接双击 `index.html` 用浏览器打开游玩：所有脚本都是普通脚本（非 ES Module），素材通过相对路径加载，`file://` 下同样可用（此时 GIF 回退解码会安静跳过）。

部署时把整个目录上传到任意静态托管（GitHub Pages、Netlify、Vercel、Nginx）即可。

## 🛠️ 技术实现

- **HTML5 Canvas 2D**：960×540 固定分辨率绘制缓冲区，CSS 自适应缩放，逻辑与设备像素比解耦
- **原生 JavaScript（ES6+）**：`src/` 下 8 个普通脚本按依赖顺序加载，通过单一 `DQM` 命名空间挂载模块，零第三方依赖、零打包
- **定步长主循环**：`requestAnimationFrame` + `dt` 上限裁剪，并暴露 `DQM.debug.step(dt)` / `pump()` 以便无头/后台环境下复现整局
- **程序化生成**：以「米」为步进门控敌人、飞鸟与道具刷新，地形生成后统一做可视性校验，避免把怪物投放到坑上
- **性能与稳定**：粒子数量上限 320、超出即淘汰最旧、离开视野的实体即时回收；天空渐变与氛围粒子按主题缓存
- **Web Audio API**：振荡器实时合成 SFX 与 6 条 16 步 BGM（含 BOSS 曲），BGM 与音效通道独立静音

## ✅ 自测情况

- 无头模拟器以脚本 AI 跑完 6 关卡 × 3 角色共 18 组合：无异常抛出，实体不堆积，粒子上限生效，绝大多数组合可通关夺旗
- BOSS 关以每角色 5 次复测：三只猫咪均能靠跳踩头部三次击毁机械犬并触发夺旗
- 浏览器实测覆盖：6 套主题渲染、HUD 文本与增益标签、连击倍率、进度百分比、选关锁定、角色锁定与解锁、暂停/重开/退出、结算面板与「下一关」跳转、`localStorage` 落盘
